# Лабораторна 3 — Діапазон і насичення

**Мета:** обирати ослаблення (attenuation) відповідно до діапазону сигналу.

## Обладнання й підключення

Потрібні ESP32-S3, потенціометр приблизно 10 кΩ, макетна плата, дроти, USB-кабель і PlatformIO. Наполегливо рекомендований мультиметр.

На знеструмленій платі під’єднайте крайні контакти потенціометра до 3V3 та GND, повзунок — до GPIO4. Мультиметр вимірює напругу між повзунком і GND. Використовуйте лише напругу в безпечних межах живленої плати: **ослаблення не захищає від перенапруги**. Див. [README](../README.md).

## Порядок роботи

1. Зберіть і завантажте [приклад 03](../examples/03_attenuation/src/main.cpp); відкрийте Serial через USB-to-UART на 115200 baud за [командами](../README.md#build-and-run).
2. Утримуйте вхід близько 0,5 В протягом повного циклу чотирьох налаштувань. Рядок друкується приблизно раз на секунду.
3. Повторіть біля 1,0; 1,5; 2,0 та 2,9 В, щоразу записуючи виміряну мультиметром напругу.
4. Між повними циклами потроху збільшуйте вхід; під час кожного циклу залишайте його сталим. Для кожного налаштування визначте область, де код майже перестає реагувати на зростання напруги.
5. Порівняйте спостереження з [таблицею приблизних вимірюваних діапазонів](../theory.md). Безпечне живлення 3,3 В не означає, що ADC вимірює 3,3 В за будь-якого ослаблення.

| Виміряний вхід, мВ | Налаштування | Сирий код | Відстеження зміни чи насичення? |
|---:|---|---:|---|
| | ADC_0db | | |
| | ADC_2_5db | | |
| | ADC_6db | | |
| | ADC_11db | | |

Повторіть таблицю для кожної напруги. Тут досліджуємо лише сирі коди; окремий приклад напруги використовує незмінне ослаблення. Деталі реалізації калібрування залишено в [нотатках викладача](../teacher_notes.md#platform--board-implementation-notes).

## Спостереження й запитання

Менше ослаблення зазвичай дає насичення за нижчої зовнішньої напруги. Код на верхній межі вже не дозволяє розрізняти всі зміни входу.

- Чому більше ослаблення може давати менший код за тієї самої напруги?
- Яке налаштування вибрати для 0,2–0,8 В, а яке — для 0,2–2,5 В? Обґрунтуйте вибір і запас.
- Чи додає ослаблення біти?
- Чому верхня межа вимірювання не є дозволом подавати довільну напругу?

**Звіт:** вимірювання, спостереження насичення та обґрунтований вибір налаштувань.
