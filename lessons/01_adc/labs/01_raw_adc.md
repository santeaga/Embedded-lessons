# Лабораторна 1 — Спостерігаємо сирий код ADC

**Мета:** побачити зміну напруги як зміну 12-бітного коду, поки що без обчислення напруги.

## Обладнання й підключення

Потрібні ESP32-S3, макетна плата, USB-кабель із передаванням даних, дроти, LDR і резистор 10 кΩ. Замість LDR-подільника можна використати потенціометр приблизно 10 кΩ. Для програмування потрібен PlatformIO.

Знеструмте плату. Зберіть **3V3 → LDR → середня точка → 10 кΩ → GND**, середню точку під’єднайте до GPIO4. Для потенціометра крайні контакти під’єднайте до 3V3 і GND, повзунок — до GPIO4.

Виконайте перевірки плати й безпеки з [README](../README.md). Не подавайте 5 В або від’ємну напругу; ослаблення не захищає від перенапруги.

## Порядок роботи

1. Перевірте спільну землю й позначки виводів. Вхід ADC не має залишатися непідключеним. Під’єднайте живлення через USB-to-UART.
2. Зберіть і завантажте [приклад 01](../examples/01_raw_adc/src/main.cpp) за [командами](../README.md#build-and-run). Відкрийте Serial на 115200 baud.
3. Повільно затінюйте й освітлюйте LDR або повертайте потенціометр. Для трьох станів входу запишіть щонайменше по п’ять кодів.
4. Визначте спостережувані мінімум і максимум. Не підвищуйте напругу за безпечні межі заради отримання крайнього коду.

|---|---|---:|---:|
| Низька напруга / темрява | | | |
| Проміжний рівень | | | |
| Висока напруга / яскраве світло | | | |

## Спостереження й запитання

За плавної зміни входу код має змінюватися, але навіть за сталого входу можливі невеликі коливання. Якщо код залишається крайнім, перевірте монтаж і насичення; одного відліку недостатньо, щоб оголосити ADC несправним.

- Чому числа коливаються, хоча освітлення на вигляд не змінилося?
- Що рахує число 4096 і чому найбільший код — 4095?
- Чи можна за кодом 4095 визначити одну точну напругу?
